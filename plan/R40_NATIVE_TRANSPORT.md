# R40 Native desktop intent transport component

One application-owned Service uses the existing startup scheduler's Native event loop. Profile normalization, filesystem/lock checks, local server/socket creation, bounded protocol reads/waits and physical destruction run there. GUI admission fencing only sets an atomic flag. A retained Service facade releases its State/Owner/scope on stop; the separate retired callback follows actual Native socket, server and lock destruction. Late Domain replies use pre-reserved bounded cells whose QObject receivers are revoked before destruction.

Role discovery precedes request transfer. A primary admits command-line inputs as one atomic Domain batch. A secondary synchronously fences its original Owner, then snapshots earlier FileOpen inputs together with arguments on that Owner's Domain key. Empty arguments still forward early FileOpen inputs. Later admissions reject explicitly. No local Source inspection identity is fabricated: remote transfer receipts and local presentation retirement remain separate facts.

One Native-generated service nonce plus the hash of each original key forms a bounded wire identity. Its immutable mapping survives the admission ACK and the sole original-key query; a reused PID/local key in another service cannot collide. StartResult retains original local producer keys in snapshot order, with corresponding known receipts or no invented receipt on Unknown. Admission is sent once. A lost/late/malformed ACK permits a query of the same wire keys, never another admission. Missing/evicted receipts, clock rollback and exhausted deadlines retain Unknown.

Endpoints use a canonical profile/network identity and same-user private access. Missing profile paths normalize through the existing canonical ancestor without creating Core's directory; normalization is rechecked before listening or forwarding. A lock and a live-endpoint probe prevent an empty second instance from stealing the listener. Unix socket paths use a checked real private directory and bounded resolved path. Windows uses UserAccessOption plus public named-pipe owner SID inspection; advapi32 is linked there. Native Windows execution remains R42 qualification.

Real BackendExecutor threads and real local sockets supplement the manual Domain/clock schedules. Two changed CPP plus seven fresh MOC units pass pinned Clang23/Bitcoin-plugin checks; app lint and two existing IPC-build process lifecycle controls pass with normal 0/fatal 1 and stderr inspection.
