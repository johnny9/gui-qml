The Native transport now offers `probeExisting(profile, network, const inputs&, completed)`. It reads the normalized profile endpoint before onboarding and can only return Missing, Forwarded, Rejected or Unknown. It never creates a profile, private IPC directory, lock or listener and never acquires Primary authority. A known absent peer leaves the original Owner queue and argument inputs untouched, so normal startup can later select its final profile. While the probe is pending, another start/probe is refused.

Rejected and Unknown are terminal for this Service. The existing transport issues one admission and only original-key queries after a lost acknowledgment; it never falls through to local startup or replays an uncertain transfer. Deadline expiry or clock rollback rejects lookup before connecting. Stop keeps the existing reserved cleanup, original Native affinity and physical-retirement receipt.
