# R33 interface limits and upstream notes

* App writers share a reservation through write/runtime/readback. Core/RPC/external writers do not participate. Version checks/readback detect conflict, without a globally atomic compare-and-write guarantee. A typed expected-version settings API returning actual persisted/runtime/readback facts would remove this gap. Never replay known persistence.
* Node lacks a typed pre-start pruned-history read; running RPC is available only later. Pre-init conservatively warns unpruning may require rebuild/download and captures acknowledgement, without claiming every pruning configuration already removed blocks. Core owns rebuild policy; exact pruned-chain process/matrix qualification stays R42.
* Structured effective configuration/proxy snapshots and side-effect-free complete proposed-config validation would simplify the adapter. Multiple/per-network proxies remain read-only; bounded summaries mark omission/truncation. Their documented list/suffix grammar is checked on Native with public ParseNetwork/endpoint helpers, preserving ordered per-network overrides for complete-policy checks and allowing unrelated saves. A real-Core getnetworkinfo control must confirm the route survives a mempool-setting save. This narrow option adapter does not claim general Core validation or modify Core policy.
* Core converts mempool MB to signed bytes, prune MiB to unsigned bytes and script-thread input to int. App representability guards reject overflow/narrowing before saving. Dry boundary review does not allocate requested resources or claim giant budgets practical. Central Core conversion validation is preferable.
* Native Qt defects are documented/deferred with local workarounds, never replacement components or Qt patches. Polling has a bounded teardown-release handoff because destruction need not publish visible=false.

If an obligation cannot be met through supported public interfaces, record the exact capability and notify the coordinator/user before Core changes. No subtree internals, hidden allocating checks or Core modifications are authorized.
